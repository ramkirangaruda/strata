What this actually is

A database engine you can read end to end in an afternoon

1

The engine

  • Write-ahead log — every write is a sequential append before it touches memory
  • Sorted string tables — immutable, prefix-compressed, written once
  • Bloom filters — skip files that provably don't have the key
  • Skiplist memtable — lock-free reads while one writer appends
2

The guarantees

  • MVCC via sequence numbers — an overwrite is a new record, never a mutation
  • Crash recovery runs on every open, not just after a kill -9
  • Six ordering rules make torn writes recoverable — see DESIGN.md §2
  • Concurrent readers take zero locks against immutable files
